# ResearchManager

A Claude Code skill for managing graduate research projects — from idea capture through paper publication.

## Usage

Install into any research project:

```bash
cd /path/to/your/research/project
ln -s /path/to/ResearchManager/skills/research-manager .claude/skills/research-manager
```

Then in that project, run `/research-manager` to start managing your research.

## What it covers

```
Idea → Goal → Survey → Route → Experiment → Analyze → Write → Submit → Revise
```

## Requirements

- Claude Code CLI
- Optional: `~/LLM-Wiki/` for cross-project knowledge reuse
